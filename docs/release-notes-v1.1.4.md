# MOHIVX Island 1.1.4

## العربية

### تحسينات الهاتف
- إضافة خيار تجريبي اختياري لفتح عارض شاشة الهاتف بجانب حافة الشاشة التي وُضع الهاتف عندها في مخطط الشاشات.
- منع التفعيل عند الحركة السريعة أو عند الحافة المشتركة بين شاشتين، وإيقاف التحكم عند انتهاء مشاركة الشاشة أو سحب الصلاحية.
- يحافظ العارض على أبعاده التي اختارها المستخدم، ويستعيد حجمه الطبيعي عند نقله إذا كان مكبّرًا.

### حدود هذه النسخة
- هذه الميزة تفتح عارض MOHIVX وتفعّل التحكم داخله؛ لا تنقل مؤشر ويندوز فعليًا إلى شاشة أندرويد.
- يلزم تشغيل مشاركة الشاشة والتحكم من الهاتف. لم يُختبر هذا الإصدار على هاتف متصل فعليًا.
- لا يتضمن هذا الإصدار تغييرًا في تطبيق Android.

## English

### Phone improvements
- Added an optional experimental edge action that opens the phone screen viewer beside the monitor edge selected on the display map.
- Fast cursor flicks and shared edges between adjacent monitors do not trigger it. Control is released when screen sharing stops or permission is revoked.
- The viewer keeps its user-selected size and restores its normal bounds when docked from a maximized state.

### Limits of this build
- This opens the MOHIVX viewer and enables interaction inside it; it does not transfer the Windows OS cursor onto Android.
- Phone screen sharing and control must be enabled on the phone. This build has not been tested with a connected phone.
- This release does not include an Android app change.
